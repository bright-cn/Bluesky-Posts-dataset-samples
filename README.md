## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `url` | Bluesky 平台上特定帖子的直接 URL。 |
| `post_id` | 每篇帖子的唯一标识符。 |
| `post_date` | 帖子发布的日期和时间。 |
| `posted_by` | 创建该帖子的用户信息，包括用户名和个人资料链接。 |
| `post_text` | 帖子的文本内容。 |
| `comments` | 帖子的评论数量。 |
| `reposts` | 帖子被其他用户转发的次数。 |
| `likes` | 帖子获得的点赞总数。 |
| `reposted` | 表示该帖子是否转发自其他用户的内容。 |
| `external_links` | 帖子中包含的外部网站链接。 |
| `images` | 帖子所附图片的数量。 |
| `videos` | 帖子所附视频的数量。 |
| `original_post` | 表示内容是原创还是转发。 |
| `pinned` | 表示帖子是否置顶于用户个人资料顶部。 |
| `discovery_input` | 用于发现内容的关键词或标签。 |
| `contains_video` | 表示帖子是否包含视频。 |
| `profile_followers_count` | 帖子创建者的粉丝数量。 |
| `profile_follows_count` | 帖子创建者关注的用户数量。 |
| `profile_posts_count` | 该用户发布的帖子总数。 |
| `post_type` | 帖子类型，例如文本、图片或视频。 |
| `video_thumbnails` | 帖子中所含视频的缩略图。 |
| `video_duration` | 帖子中所含视频的时长，以秒为单位。 |


## 使用场景

### 1. 社交媒体情绪分析
通过分析帖子的文本内容和互动指标，了解公众对各种议题的情绪。

### 2. 影响者影响力评估
通过分析粉丝数量和互动率来评估不同用户的影响力，并识别关键影响者。

### 3. 内容表现基准分析
比较不同个人资料所发布帖子的表现，以确定最佳实践并优化内容策略。
